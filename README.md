Neuroevolution Walking Agent

This project implements a neuroevolution-based reinforcement learning system that teaches an AI agent how to walk in a 2D physics environment. The simulation is built using Pygame for rendering and Pymunk for realistic physics, while a custom neural network is evolved over generations to produce stable locomotion. The project is built to allow the agent complete control over a physics body and partial control to simulate a prosthetic.

Rather than using gradient-based learning (e.g. backpropagation), this project evolves neural networks using genetic algorithms—selecting, mutating, and breeding agents based on how well they learn to walk.
